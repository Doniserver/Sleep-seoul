# 지표·점수 산식

코드 기준값은 `pipeline/config.py`, 계산은 `pipeline/metrics.py`·`clean.py`·`aggregate.py`에 있다. 바꾸면 이 문서도 함께 고친다.

## 0. 이 값이 뜻하는 것

- **동네 바깥(길가 센서) 환경**이다. 집 안 소음이 아니다.
- S-DoT는 **간이측정기**(성능인증 1등급)다. 법정 측정이 아니라 **비교용 지표**다.
- 센서 하한은 **35dB**다. 35dB는 "35dB 이하"를 뜻한다.
- 층간소음 등급은 측정값이 아니라 **건축 시기로 추정**한 값이다.

## 1. 시간

- 측정시간 표기(예: `07:07`)는 1시간 구간의 끝이다. 구간 시작 = 표기 − 1시간(정각으로 내림).
- **밤 = 구간 시작이 22, 23, 0, 1, 2, 3, 4, 5시인 8시간.** 그 밤의 날짜는 22시가 시작된 날이다.
- 유효한 밤 = 8시간 중 **6시간 이상** 값이 있는 밤.

## 2. 밤 소음 L_night

```
에너지 평균: L = 10 · log10( mean( 10^(L_i / 10) ) )
```

1. 센서 L_night = 기간 안 유효한 밤의 모든 밤 시간 값(1시간 평균)을 에너지 평균.
2. 행정동 L_night = 그 동 대표 센서들의 L_night **중앙값**.
3. 대표 센서: `지역 = residential_area`(주거지역). 주거 센서가 없는 동은 `parks`, `roads_and_parks`를 뺀 다른 센서를 쓰고 화면에 "비주거 센서"라고 표시.
4. 센서가 없는 동은 **보간하지 않고** "데이터 없음".
5. S-DoT 1시간 평균은 계산 방식이 공개돼 있지 않아 **산술평균으로 가정**했다.

시간대별 지도(슬라이더): 센서별로 같은 시각(예: 2시)의 값들을 에너지 평균 → 동 중앙값.
요일×시간 히트맵: 센서별 (요일, 시) 칸의 에너지 평균 → 동 중앙값. 낮 시간도 포함.
월별: 같은 방법을 그 달의 밤만으로 계산.

## 3. 기준선 (화면에 선으로 표시)

| 선 | 값 | 출처 |
|---|---|---|
| WHO 야간 목표 | 40dB | WHO Night Noise Guidelines for Europe(2009), L_night,outside 연평균 |
| WHO 도로교통 야간 권고 | 45dB | WHO Environmental Noise Guidelines(2018), 도로교통 L_night |
| WHO 중간 목표 | 55dB | WHO NNG(2009) interim target |

WHO 기준은 1년 평균이다. 현재 기간(29일)으로 견주는 것은 참고용이다.

## 4. 보조 지표

| 지표 | 정의 |
|---|---|
| 피크 횟수 | 센서별 (밤 시간 중 `소음 최대` > 70dB인 시간 수) ÷ (유효한 밤 수) → 동 중앙값. 단위 회/밤 |
| 주말 효과 | 센서별 (금·토 밤 L_night) − (일~목 밤 L_night) → 동 중앙값 |
| 밤 밝기 | 센서별 밤 시간 `조도 평균`의 중앙값 → 동 중앙값. 참고선 10 lux(서울시 주거지역 빛공해 허용 기준) |
| 조용한 밤 비율 | 동의 하룻밤 값(센서별 하룻밤 L → 동 중앙값)이 45dB 미만인 밤 ÷ 전체 밤 |

## 5. 수면 점수 (0~100, **잠정 — 팀 확정 필요**)

```
소음 점수 = 100                       (L_night ≤ 40)
          = 100 · (65 − L) / (65 − 40)  (40 < L < 65)
          = 0                         (L_night ≥ 65)
감점: 밤 밝기 > 10 lux 이면 −5
      피크 1회/밤마다 −2 (최대 −10)
수면 점수 = clamp(소음 점수 − 감점, 0, 100), 반올림
```

## 6. 데이터 정리와 이상치 제거

| 단계 | 규칙 | 기록 |
|---|---|---|
| 범위 밖 값 | 소음 평균 20~130dB, 최대 20~140dB, 조도 0 이상이 아니면 결측 처리 | — |
| 고장 의심 센서 | 기간 내내 소음 평균의 표준편차가 0 | `excluded.json` type=sensor |
| 결측 많은 센서 | 밤 시간 결측률 > 30% | `excluded.json` type=sensor |
| 조도 이상 | 밤 조도 중앙값 > 2000 lux → 그 센서의 조도만 제외 | type=sensor_lux |
| **이상치 밤** | 센서의 하룻밤 L이 그 센서 밤 L 중앙값보다 **8dB 이상** 높음 → 공사·축제·일시 고장으로 보고 기본 통계에서 제외 | type=night (센서, 날짜, 차이) |

## 7. 소음 패턴 자동 분류 (AI)

1. 행정동마다 7×24 히트맵(dB). 빈 칸이 10%를 넘는 동은 분류하지 않는다. 빈 칸은 같은 시각의 다른 요일 평균으로 채운다(분류에만 사용).
2. 동마다 168칸 평균을 빼서 **크기가 아닌 모양**만 남긴다.
3. k-means(k=3, k-means++ 초기화, 10회 시작 중 최소 관성, seed 42).
4. 이름은 군집 중심의 특징으로 **사람이 정한 규칙**에 따라 붙인다:
   - 금·토 밤이 다른 밤보다 1dB 이상 높으면 **주말 밤 활발형**
   - 나머지는 (낮 9~18시 평균 − 밤 평균)이 큰 순서대로 **밤에 조용해지는 주거형 / 생활 소음형 / 밤에도 이어지는 소음형**
5. 크기(얼마나 시끄러운지)는 이름에 쓰지 않는다. 같은 유형 안에서도 시끄러운 동과 조용한 동이 섞인다.

## 8. 층간소음 위험 등급 (건물 단위, 추정)

| 등급 | 사용승인일 | 근거 |
|---|---|---|
| 높음 | ~2007-12-31 | 2005-07 이전 사업승인: 슬래브 120~180mm면 통과 |
| 보통 | 2008 ~ 2016 | 2005-07 표준바닥구조 도입 ~ 2014-05 강화 전 |
| 낮음 | 2017-01-01 ~ 2025-08-03 | 2014-05 이후 사업승인: 벽식 210mm·기둥식 150mm 이상 + 충격음 기준 |
| 측정 기준 적용 | 2025-08-04 ~ | 2022-08-04 이후 사업승인(사후확인제, 실측 49dB 이하) + 약 3년 |

- 제도는 사업승인일 기준, 공개 데이터는 사용승인일이라 2~3년 시차를 감안했다.
- K-APT 기본정보에 구조(벽식·기둥식) 필드가 없어 기둥식 보정은 하지 않는다.
- 좌표가 없어 **법정동 단위로 등급을 세고**, 같은 구 안에서 행정동 이름의 숫자를 뗀 이름(역삼1동→역삼동)이 같은 법정동에 연결한다.
- 화면 문구: "건축 시기 기준 추정 등급이며 실제 소음과 다를 수 있습니다."

## 9. AI 동네 리포트 (보류)

예정: 확정된 숫자를 프롬프트에 넣고 문장만 생성 → 문장 속 모든 숫자가 입력 숫자 목록에 있는지 검사 → 하나라도 다르면 폐기. 결과는 `dongs_stats.json`의 `report` 칸(`text`, `generated_at`, `method`, `verified`)에 넣는다. 비어 있으면 화면에 "준비 중".

## 10. 연도별 보기

- 원자료: S-DoT 연도 묶음 파일(`S-DoT_NATURE_{연도}년(...).zip`, 2020~2025). 2026년부터는 매일 API로 모은 시간별 자료(`data/hourly`).
- **끝난 해만** 연도 목록에 넣는다(진행 중인 해는 "최근 기간"에서 본다). 해가 바뀌면 매일 갱신 작업이 지난해를 자동으로 계산한다.
- 이미 더 완전한 결과(밤 수가 더 많음)가 있으면 자동 계산이 덮어쓰지 않는다. 예: 2026년은 매일 수집이 10월부터라 자동 계산은 일부 기간이 되므로, 2027년 초 서울시가 2026년 zip을 올리면 한 번 받아 넣어 다시 계산한다.
- 연도는 **밤 날짜(22시가 시작된 날)의 연도**로 나눈다. 계산 방법(정제·이상치 제거·에너지 평균·동 중앙값)은 최근 기간과 같다.
- 2020년(4월부터)과 진행 중인 해는 **일부 기간**이다. 밤이 330일보다 적으면 화면에 "일부"로 표시한다.
- 행정동 경계는 모든 연도에 2026-10-01 기준을 쓴다. 과거 행정동 변경은 반영하지 않는다.
- 센서 위치는 2026-03 설치 위치정보로 판정하고, 목록에 없는 옛 센서는 같은 구·같은 동 이름을 가진 센서의 행정동을 쓴다.
- 산출: `pipeline/yearly.py` → `web/public/data/years/` (연도별 동 지표, 1년 달력, 동별 연도 추이).
