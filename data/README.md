# data 폴더 안내

자료를 **어디서 받았는지**에 따라 폴더를 나눴습니다. 폴더 이름이 곧 출처입니다.

```
data/
├─ 서울열린데이터광장/      서울시 S-DoT 센서 자료
│  ├─ 원본/                 내려받은 파일 그대로 (연도 zip, 주간 CSV, 위치정보, API 명세서)
│  ├─ 매일수집/              API로 매일 받은 시간별 자료
│  ├─ 센서위치_사본/         위치정보 파일 사본 (자동 갱신용)
│  └─ 연도별정리/            연도 zip을 풀어 정리한 것
├─ 브이월드/                국토교통부: 도로·철도·건물
├─ 공공데이터포털/           상가정보(업소), 공동주택
├─ 공개저장소_행정동경계/     행정동 경계
└─ 분석임시/                조사 때 만든 임시 파일 (사이트에 쓰이지 않음)
```

사이트가 실제로 읽는 결과 파일은 `web/public/data/`에 따로 있습니다(맨 아래 표).

## 서울열린데이터광장 (서울특별시)

- 데이터셋: 스마트서울 도시데이터 센서(S-DoT) 환경정보, OA-15969
- 주소: https://data.seoul.go.kr/dataList/OA-15969/S/1/datasetView.do

| 위치 | 내용 | 받는 방법 | 저장소 |
|---|---|---|---|
| `원본/S-DoT_NATURE_{연도}년(...).zip` | 센서별 1시간 단위 소음·조도, 1년치 | 데이터셋 페이지 파일 탭에서 직접 내려받기 | 올리지 않음 |
| `원본/S-DoT_NATURE_YYYY.MM.DD-MM.DD.csv` | 같은 자료의 주간 파일 | 위와 같음 | 올리지 않음 |
| `원본/…설치 위치정보.xlsx` | 센서 좌표, 설치 장소 구분 | 같은 페이지의 첨부파일 | 올리지 않음 |
| `원본/…Open API 명세서(20250716).xlsx` | API 항목 이름 확인용 | 같은 페이지의 첨부파일 | 올리지 않음 |
| `매일수집/YYYY-MM-DD.parquet` | 하루치 시간별 소음·조도 | API `IotVdata017` (최근 한 달만 제공) → `python -m pipeline.fetch_sdot api` | 올림 |
| `센서위치_사본/…설치 위치정보.xlsx` | `원본/`의 위치정보 사본 | 직접 복사 | 올림 |
| `연도별정리/{연도}.parquet` | 연도 zip을 풀어 정리한 시간 자료 | `python -m pipeline.yearly` | 올리지 않음 |

쓰임: 사이트의 모든 소음·밝기 숫자의 바탕입니다.

## 브이월드 (국토교통부 공간정보 오픈플랫폼)

- 주소: https://www.vworld.kr (2D 데이터 API, 인증키 필요)

| 위치 | 내용 | 브이월드 자료 이름 | 받는 명령 |
|---|---|---|---|
| `roads.parquet` | 도로중심선 13만 개 (차로 수·폭) | `LT_L_N3A0020000` | `python -m pipeline.fetch_roads` |
| `rail.parquet` | 철도시설 1,043곳 | `LT_C_UPISUQ152` | `python -m pipeline.fetch_context` |
| `bldg/` | 건물 128만 동 (높이·모양) | `LT_C_BLDGINFO` | `python -m pipeline.fetch_bldg` |

쓰임: 10m 상세 지도 계산과 주의 표시. 저장소에는 올리지 않습니다.
화면의 배경지도·항공사진·3D 지도·장소 검색도 브이월드이지만, 그것은 파일로 받지 않고 화면에서 바로 불러옵니다.

## 공공데이터포털 (data.go.kr)

| 위치 | 내용 | 제공 기관 | 받는 명령 |
|---|---|---|---|
| `상가정보/stores_seoul.parquet` | 음식점·술집·노래방·숙박 17만 곳 | 소상공인시장진흥공단 상가(상권)정보 API | `python -m pipeline.fetch_context` |
| `공동주택/` (아직 없음) | 공동주택 사용승인일·세대수 | 국토교통부 공동주택 기본정보 API | `python -m pipeline.fetch_buildings` |

쓰임: 상가정보는 상세 지도 계산과 주의 표시, 공동주택은 층간소음 추정(준비 중). 저장소에는 올리지 않습니다.

## 분석임시

정확도 조사 때 만든 임시 파일과 실행 기록입니다. 사이트에 쓰이지 않으며 지워도 됩니다.

## 사이트가 읽는 결과 (`web/public/data/`)

| 파일 | 내용 | 바탕 자료 | 만드는 명령 |
|---|---|---|---|
| `years/{연도}.json` 등 | 동네별 밤·낮 소음, 점수, 달력, 센서 값 (가장 최근에 끝난 한 해) | 서울열린데이터광장 | `python -m pipeline.yearly` |
| `noisemap/night_{연도}.png`, `day_{연도}.png` | 10m 칸 상세 추정 지도 (밤·낮) | 서울열린데이터광장 + 브이월드 + 공공데이터포털 | `python -m pipeline.noisemap` |
| `noisemap/flags.png` | 자리별 주의 표시 | 브이월드 + 공공데이터포털 | `python -m pipeline.noisemap` |
| `dongs.geojson` | 지도에 그리는 동네 경계 | 공개저장소_행정동경계 | `python -m pipeline.build` |
| `meta.json`, `dongs_stats.json` 등 | 최근 한 달 집계와 기준값 | 서울열린데이터광장 (매일수집) | `python -m pipeline.build` |

## 지킬 것

- "올리지 않음"으로 적힌 폴더는 용량이 크거나 원본 배포 조건이 있어 GitHub에 올리지 않습니다. 필요한 사람은 위 표의 방법으로 직접 받습니다.
- 인증키는 맨 위 폴더의 `.env`에만 둡니다.
- 새 자료를 추가하면 출처 이름의 폴더에 넣고, 이 문서의 표에 한 줄을 더합니다.
